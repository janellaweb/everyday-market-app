## Everyday Market App

## Overview
This Everyday Market App is now updated to have implemented Angular routing and a reactive registration form with validation.

## Testing

Tested using ng test and ng lint
 
## Running the Project

Install this first:

npm install

Then Run it: 

ng serve

Open in browser:
http://localhost:4200/
